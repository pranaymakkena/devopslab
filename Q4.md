# Q4: Jenkins Installation and Setup

## Aim

To install Jenkins, configure it, and explore the Jenkins environment.

---

## Prerequisites

Install Java before installing Jenkins.

Check the Java installation:

```bash
java -version
```

---

## Jenkins Installation

1. Download and install Jenkins.
2. Start the Jenkins service.

### Start Jenkins

```bash
net start Jenkins
```

### Check Jenkins Service Status

```bash
sc query Jenkins
```

### Stop Jenkins

```bash
net stop Jenkins
```

### Restart Jenkins

```bash
net stop Jenkins
net start Jenkins
```

---

## Open Jenkins

After starting Jenkins, open the following address in a browser:

```text
http://localhost:8080
```

---

## Initial Setup

1. Open Jenkins in the browser.
2. Enter the initial administrator password.
3. Install the suggested plugins.
4. Create an administrator account.
5. Log in to the Jenkins dashboard.

---

## Creating a Sample Jenkins Project

Follow these steps:

1. Open the Jenkins Dashboard.
2. Click **New Item**.
3. Enter a project name.
4. Select **Freestyle Project**.
5. Click **OK**.

---

## Add Build Step

Go to:

```text
Build Steps → Execute Windows Batch Command
```

Enter the following command:

```bash
echo Hello Jenkins
echo Jenkins installation is successful
```

Click **Save**.

---

## Execute the Project

1. Click **Build Now**.
2. Open the completed build.
3. Click **Console Output**.

### Expected Output

```text
Hello Jenkins
Jenkins installation is successful
```

---

## Useful Commands

| Command             | Description             |
| ------------------- | ----------------------- |
| `java -version`     | Check Java installation |
| `sc query Jenkins`  | Check Jenkins service   |
| `net start Jenkins` | Start Jenkins           |
| `net stop Jenkins`  | Stop Jenkins            |

---

## Result

Thus, Jenkins was successfully installed and configured. The Jenkins environment was explored by creating and executing a sample project.
